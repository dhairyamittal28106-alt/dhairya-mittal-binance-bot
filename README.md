# Binance Futures Trading Bot

Python CLI for market and limit orders on Binance USDT-M Futures Testnet, with OCO and TWAP helpers. Application is under dhairya_mittal_binance_bot/.

    cd dhairya_mittal_binance_bot
    python -m venv .venv
    pip install -r requirements.txt
    python src/main.py

Activate the virtual environment before installing. Create a private .env with testnet API credentials; keep them secret and test on testnet.
